# ASTERA LAB — 첫 구현 기준

초등 4–6학년 학생이 웹에서 5–10분 동안 질문을 세우고, 직접 조사하고, 근거를 붙여 생각을 수정하는 학습 공간을 만든다. 기존 Next.js 사이트와 Supabase/Toss 구조를 유지한다. 로그인 없이 LAB을 경험하고, 교사가 만든 워크북·가이드는 추후 파일 경로가 확정되면 별도로 연결한다.

## 참고 및 디자인 결정

2026-10-10 현재 ASTERA 배포 화면, 기존 SCIENCE 001 교수·학습 지도안, ASTERA 브랜드 자료를 1차 기준으로 사용했다. Refero의 스타일·학습 화면 검색은 NO_SUBSCRIPTION으로 실패했다. 이를 다른 제품을 검토한 것처럼 보고하지 않는다. 대안은 Refero skill의 craft-details 지침과 기존 제품 화면이다.

네이비 #071A3D는 탐구 배경, 금색 #D9A441은 주요 행동, SCIENCE #1F9D7A는 분야 식별에 사용한다. 기존 본문 글꼴을 유지하며 16px 이상 활동 본문, 44px 이상 주요 터치 영역, 보이는 초점, 축소 동작 설정을 지원한다.

## 개발 순서와 완료 기준

1. SCIENCE 001 / LIFE FINDER: 관찰 예산 선택 → 자료 공개 → 우선순위와 근거 → 환경에 맞춘 생명체 설계 → 성찰.
2. TECH 001 / CHOICE LENS: 추천 규칙과 노출 다양성 비교. 실제 서비스 알고리즘을 재현한다고 주장하지 않는다.
3. HISTORY 001 / SOURCE DETECTIVE: 같은 사건에 대한 창작 사료의 관점·목적·누락 비교.
4. ECONOMY 001 / FAIR CHOICE: 동일 분배·필요 기반 분배·절충안의 영향을 비교.
5. LITERATURE 001 / STORY LENS: 연령에 맞춘 문학 장면을 다른 화자의 관점에서 다시 쓰기.
6. ART 001 / ART LENS: 작품 요소·맥락과 해석의 연결.
7. HUMAN 001 / DIALOGUE BRIDGE: 관점과 필요를 구분하고 함께 결정하기.
8. ENGINEERING 001 / DESIGN FOR ALL: 사용자 조건을 바꾸며 접근 가능한 설계를 시험하기.

각 후속 앱은 고유한 선택과 피드백을 구현한 후에만 '체험 가능'으로 공개한다. 공통 목록의 기획 항목은 실행 버튼을 제공하지 않는다. FUTURE는 별도의 교차 주제이며 아홉 번째 유니버스로 추가하지 않는다.

## 첫 앱의 기록과 범위

버전이 붙은 로컬 저장 기록을 사용한다. 정답 자동 판정, 학생 식별, 외부 AI 호출, 학급 대시보드는 이번 범위에 포함하지 않는다. 탐사 대상과 관찰 수치는 교육용 가상 자료임을 활동 안에 표시한다. 실제 외계행성 측정 자료와 혼동하지 않도록 한다. 교사 PDF 파일은 제공받기 전까지 다운로드 버튼을 만들지 않는다.

단위 검증: 조사 중복 결제, 예산 초과, 저장 자료 복구, 성찰의 필수 근거, 완료 조건. 전체 검증: 홈/상세 → LAB → 탐사 → 저장/재진입 → 최종 기록, 모바일 화면과 키보드.
