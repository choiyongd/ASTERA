# 학습자료 관리와 온라인 학습 설계

기존 ASTERA 화면을 주 시각 기준으로 삼는다. 네이비 헤더, 골드 강조, IBM Plex Sans KR, 밝은 기록 패널을 유지한다. Refero 검색은 NO_SUBSCRIPTION으로 사용할 수 없어 기존 LAB과 craft-details 지침을 참조했다.

| 결정               | 근거                    | 적용                                 |
| ------------------ | ----------------------- | ------------------------------------ |
| 기존 색과 글꼴     | globals.css / 기존 LAB  | 관리·학습 화면 공통                  |
| 5단계, 총 20분     | 사용자 요구 / 기존 과정 | 2·4·8·4·2분 안내                     |
| 초안과 발행본 분리 | 수정 반영 요구          | 발행 트랜잭션, 버전 복구             |
| 무료 체험 지정     | 제한 이용 요구          | 공개·회원·멤버십 세 범위             |
| 개인 진도 저장     | 온라인 학습 요구        | 계정·발행 버전별 저장, 충돌 감지     |
| PDF와 HTML 격리    | 업로드 파일 유형        | 비공개 버킷, 권한 검사, HTML sandbox |

실제 자료를 임의로 생성해 발행하지 않는다. 관리자가 자료를 등록하고 발행해야 학습 목록에 나타난다. 기존 LAB은 무료 체험로 유지하며 새 과정은 자료 관리 화면의 공개 범위를 따른다.
## 마이페이지와 페이지 관리 확장

학습 그래프는 저장된 기록만 사용한다. 유니버스별 완료율은 현재 발행본을 기준으로 계산한다. 4가지 역량의 학습 전후 자기평가(1~5)를 비교하며 이를 객관적 성적이나 향상 진단으로 표시하지 않는다. 반복한 주제는 최신 완료 기록만 집계하고 데이터가 없으면 빈 상태로 둔다. 차트는 표기된 수치와 날짜별 텍스트도 함께 제공한다.

안내 페이지 관리는 텍스트 섹션을 편집·미리보기·발행하는 방식이다. 본문을 HTML로 실행하지 않는다. 관리자 권한은 이메일 인증과 별도 Firestore 역할 문서로 확인하며, 관리자 이메일 자체를 공개 소스에 고정하지 않는다.
