# ASTERA 전 주제 LAB 구현 기준

2026-10-10. 사용자가 긍정적으로 평가한 SCIENCE 001을 1차 제품 기준으로 삼는다. 기존 공식 로고·네이비 탐구 공간·밝은 기록 패널·5단계 학습을 유지한다. Refero의 라이브 검색은 앞선 조사에서 구독 제한으로 이용하지 못했으며 기존 SCIENCE 화면, 브랜드 가이드와 craft/motion 지침을 기준으로 구현한다.

## 범위와 연결

첫 8개 유니버스의 001 주제를 모두 실행 가능한 LAB으로 만든다. 기존 라이브러리의 별도 9개 주제는 삭제하거나 무관한 001에 연결하지 않고 각각의 질문에 맞는 활동 경로를 제공한다. 각 상세의 ‘학습 시작하기’와 LAB 배너는 같은 labId를 참조한다. 신규 001 주제 7개를 기존 라이브러리에 추가한다.

| 주제 | 탐구에서 바꾸거나 비교하는 것 | 남기는 근거 |
| --- | --- | --- |
| TECH 001 | 관심 분야·새로운 분야 노출 비율 | 추천 목록의 분야 수와 선택 이유 |
| HISTORY 001 | 기록 작성자·목적·누락 | 같은 사건의 창작 사료 비교 |
| ECONOMY 001 | 12개 자원의 분배 방식 | 필요 충족과 남은 부족량 |
| LITERATURE 001 | 세계 문학 장면의 화자 | 본문 단서와 인물의 생각, 다시 쓴 장면 |
| ART 001 | 실제 공개 소장품의 시각 요소와 맥락 | 색·구도·소재의 관찰과 해석 |
| HUMAN 001 | 공동 공간의 규칙과 합의안 | 서로 다른 필요와 실제 확인할 조건 |
| ENGINEERING 001 | 접근 조건·자원 제약·사용자 | 설계 시험 결과와 수정안 |

모든 LAB은 핵심 질문·개념 읽기와 이해 확인·가설 및 비교 실험·창작/설계·전후 성찰을 제공한다. 동일 조건의 반복을 새 실험으로 계산하지 않는다. 2개 이상의 서로 다른 조건을 비교하고 실제 기록에서 근거를 선택해야 탐색이 완료된다. 정답 점수를 행동·의견 평가로 사용하지 않는다. 가상 자료와 실제 자료, 모형의 한계를 활동 안에 표시한다.

주제별 기록은 별도 키로 저장하며 복구 시 스냅샷을 입력에서 재계산한다. 완료 여부·진행 단계·근거도 다시 검증한다. 저장이 차단되면 현재 활동을 계속하고 다운로드로 보관하도록 안내한다. 초기화는 확인 창을 거친다. 네트워크 AI·학생 개인정보·결제 없이 공개 체험을 제공한다.

## 변경 결정

- 진입 화면: sessionStorage의 한 번 재생 조건 제거. 로고가 준비된 후 약 2초간 재생하며, 내부 링크 이동에는 재생하지 않는다. 동작 줄이기·건너뛰기·Esc·CSS 기본 종료 유지.
- 메뉴: ASTERA 소개 → 탐험하기 → 유니버스 → ASTERA LAB → 학습도구 → 커뮤니티 → 요금제.
- 라이브러리: 자체 검색창에서 주제명·코드·키워드를 검색하고 기존 필터와 함께 적용한다.
- 문학: Andersen의 공개 원작을 바탕으로 한국어 교육용 장면을 새로 재구성하며 현대 번역을 복제하지 않는다.
- 예술: 박물관 API가 Public Domain으로 명시한 이미지와 소장품 설명을 사용하고 출처를 제공한다.
- 계산·도식: 정확한 입력-출력 비교를 위한 코드 도형을 사용한다. 모형 값을 실제 측정·확률·구조 안전 계산으로 표현하지 않는다.

검증은 실제 비교 결과, 제약과 경계값, 중복 실험, 기록 변조/복구, 단계 우회, 전 주제 연결과 전체 빌드를 포함한다. 보호된 미리보기의 브라우저 접근 제한은 별도로 보고한다.
