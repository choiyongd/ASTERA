## 브라우저에서 확인할 항목

보호된 Vercel 미리보기의 실제 렌더링과 클릭 흐름은 접근 가능 여부를 확인한 뒤 검증해야 한다. 정적 HTML 검증을 픽셀 단위 화면 검증으로 간주하지 않는다.

1. 새 탭에서 첫 접속: 공식 로고 → 한국어 슬로건 순서로 나타나며 약 2초 후 페이지가 열리는지 확인.
2. 건너뛰기·Esc 후 즉시 페이지에 진입하고 키보드 초점이 본문으로 이동하는지 확인.
3. 같은 탭에서 내부 이동과 새로고침을 해도 진입 화면이 반복되지 않는지 확인.
4. 동작 줄이기 설정에서 즉시 진입, sessionStorage 차단 시에도 정상 종료, 느린 스크립트 로딩과 JavaScript 비활성화 시에도 페이지 진입을 막지 않는지 확인.
5. 로그인 전후, 320·390·768·1024·1440px 폭에서 헤더 겹침과 가로 넘침 확인. 좁은 화면의 햄버거 메뉴에서도 소개 페이지가 열려야 한다.
6. 홈 빠른 메뉴·유니버스 영역·콘텐츠 타일, 모든 상세 단계, LAB 목록, 소개의 심볼이 잘리지 않으며 서로 같은 로고인지 확인.
7. 소개 목차와 각 LAB 링크, 현재 페이지 표시를 키보드로 확인.
8. SCIENCE 001에서 기록 작성·예산 조사·성찰·재진입이 기존대로 작동하는지 확인.

변경사항은 기존 `codex/astera-lab-science-001` 리뷰 브랜치에 반영한다. 프로덕션 반영 여부와 실제 브라우저 검증 결과는 배포 상태와 함께 별도 보고한다.
