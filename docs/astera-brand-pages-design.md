# ASTERA 진입 화면과 소개 페이지

## 구현 기준

기존 ASTERA 사이트를 사용하는 학생·교사·보호자가 첫 접속에서 브랜드를 알아보고, 소개 페이지에서 학습의 목적과 실제 사용 방법을 이해하도록 한다. 기존 Next.js 사이트, 공식 마스터 로고와 새 유니버스 심볼을 유지한다. 사용자가 요청한 세 가지 기능을 기존 리뷰 브랜치에 직접 구현한다.

1차 시각 기준은 현재 ASTERA 배포 화면, `ASTERA_Brand_Identity_Guide_v1.0(1).pdf`, `astera-brand-tokens.json`, 기존 홍보 패키지의 공식 로고·유니버스 v3 심볼이다. 라이브 Refero 검색은 앞선 조사에서 NO_SUBSCRIPTION으로 차단되었다. Refero의 craft-details와 motion 지침을 접근성·간격·전환에 보조 적용한다. 기존 밤하늘 일러스트와 네이비·골드 방향을 주된 기준으로 유지한다.

| 결정 | 근거 | 적용 |
| --- | --- | --- |
| 약 2초의 첫 진입 화면 | 사용자의 명시적 요청 | 공식 로고가 나타나고 한국어 슬로건이 순서대로 등장한 뒤 종료 |
| 같은 탭에서는 한 번만 재생 | 페이지 탐색을 방해하지 않는 전환 원칙 | sessionStorage로 재생 여부 기록, 내부 이동에는 재생하지 않음 |
| 생략·Esc·동작 줄이기 지원 | Refero motion 및 접근성 지침 | 언제든 건너뛰기, reduced motion에서는 즉시 진입 |
| 스크립트가 없어도 종료 | 페이지 진입을 막지 않는 기본 기능 | CSS 자체 종료, 배경 inert는 클라이언트가 작동할 때만 적용 |
| 마스터 로고 원형 유지 | 브랜드 가이드의 CI 규칙 | 변형·회전·재채색 없이 공식 이미지 사용, 내비게이션 최소 폭 160px |
| 유니버스 심볼 한 곳에서 관리 | 모든 페이지에 새 로고 적용 요청 | UniverseIcon에 공식 v3 파일 연결, 홈·상세·LAB·소개에서 공유 |
| 소개를 실제 학습과 연결 | 브랜드의 질문·근거·창작 원칙 | 핵심 질문 → 개념 → 탐색 → 응용 → 성찰과 SCIENCE 001 예시 설명 |
| 비전과 제공 상태 구분 | 브랜드의 정직한 말하기 원칙 | SCIENCE 001 체험, 나머지 7개 개발 예정, PDF·교사/가정 도구는 확장 방향으로 표시 |

소개 페이지는 큰 일러스트를 사용하는 첫 화면, 넉넉한 여백의 설명 본문, 탐구 단계와 실제 질문 목록 순서로 구성한다. 모든 설명을 같은 작은 카드에 담지 않는다. 네이비는 브랜드와 탐구 배경, 아이보리는 읽기 표면, 금색은 강조, 각 유니버스 색은 분야 구분에만 쓴다. 한국어 브랜드 슬로건은 Noto Serif KR Bold, 나머지 UI는 기존 본문 글꼴을 사용한다. 좁은 화면에서는 단일 열로 흐르고 상단 메뉴는 햄버거 안에서 같은 링크를 제공한다.

## 완료 기준

- 최초 진입 약 2초 후 종료, 건너뛰기와 Esc, 재진입·동작 줄이기·저장 차단 상황 확인.
- 홈 빠른 메뉴·유니버스 목록·콘텐츠 타일·상세 단계·LAB·소개에 동일한 공식 심볼 사용.
- 상단 ‘ASTERA 소개’의 데스크톱/모바일 링크와 현재 페이지 표시.
- 소개 페이지에서 철학·목표·비전·학습 방식·8개 주제·확장 계획과 체험 링크 확인.
- 기존 학습 상태 테스트 및 전체 프로덕션 빌드. 실제 화면 검증은 Vercel 보호 배포 접근 가능 여부를 별도 기록.
