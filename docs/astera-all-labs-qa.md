## 검증 범위의 한계와 후속 확인

React 입력/상태 검증은 브라우저의 픽셀 배치·실제 CSS 애니메이션·인쇄 엔진의 검증과 다르다. 보호된 Vercel 미리보기는 검증용 브라우저에서 로그인 화면으로 이동했고 연결 도구의 보호 페이지 접근도 허용되지 않았다. 따라서 로그인한 사용자 브라우저에서 375px/768px/1440px 화면의 실제 줄바꿈·키보드 포커스·2초 표시·인쇄 여백을 최종 확인해야 한다. 보호 설정은 변경하지 않았다.

읽기·창작·성찰을 모두 정성스럽게 마치는 시간은 5–10분보다 길 수 있다. 앱은 핵심 비교 5–10분과 확장 학습을 구분해 안내한다. 수업용 규칙값은 실제 예측·확률·물리 안전 계산이 아니며 활동과 결과에서 범위를 표시한다. 공개 체험의 완료 표시는 학습자의 생각에 대한 점수나 검증된 성취도 판정이 아니다.

PDF 워크북·가이드와 교사 계정/공유 기록은 별도 개발 범위로 남겨두며, 이번 LAB의 텍스트 다운로드와 브라우저 인쇄/PDF 저장으로 자신의 탐구 기록을 보관할 수 있다.
